# KodeKloud-100-Days-Of-DevOps-Challenge

My hands-on journey through KodeKloud's 100 Days of DevOps Challenge — documenting every
day as I go, from Linux fundamentals through Docker, Kubernetes, Git, Ansible, and more.

This repo holds my own solutions, notes, and explanations for each day's task. I'm building
this step by step as a way to actually learn by doing, not just to have a checklist of
completed tasks — so expect real notes on what I did, what tripped me up, and what I took
away from each challenge.
