# Day 007: Linux SSH Automation

## 🎯 What I Did Today

Today's task was about setting up password-lessSSH access, 
So a jump host user can run automated scripts against app servers 
withoutanyone typing a password every time.

**The scenario**: user `thor` on the jump host needs password-less SSH access into each
app server, through that server's own sudo user (e.g. `tony` on App Server 1).


## Steps I Followed

1. On the jump host, generated an SSH key pair for `thor`:

    ```sh
    ssh-keygen -t rsa -b 2048
    ```

    This creates a private key (stays on the jump host, never shared) and a public key
    (safe to distribute).

2. For each app server, made sure the target user had a `.ssh` directory, then added the
   jump host's public key to that user's `authorized_keys`:

    ```sh
    mkdir -p .ssh
    vi .ssh/authorized_keys
    ```

    Pasted the contents of `id_rsa.pub` from the jump host in there.

## Doing It the Automated Way

Instead of manually creating directories and pasting keys on every server, `ssh-copy-id`
does the whole thing in one command — creates `.ssh` if it's missing, sets the right
permissions, and appends the key to `authorized_keys`:

```sh
ssh-copy-id user@host
```

Much faster once there are multiple app servers involved, and less room for a manual
mistake (wrong permissions, wrong file, etc.).

## What I Took Away From This

- Password-less doesn't mean insecure — it's actually stronger than password auth, since
  it removes the whole brute-force-the-password attack surface
- The private key never leaves the machine that generated it — only the public key gets
  copied around
- Permissions matter a lot here: SSH will silently refuse to use a key setup if the
  permissions on `.ssh` or the key files are too open
- `ssh-copy-id` exists specifically so you don't have to do the manual mkdir/vi/paste dance
  on every single server

## Notes to Self

| Item | Detail |
|---|---|
| Private key | Keep secret — never leave the source machine |
| Public key | Safe to share — this is what gets copied to servers |
| Private key location | `~/.ssh/id_rsa` |
| Public key location | `~/.ssh/id_rsa.pub` |

| Path | Required Permissions |
|---|---|
| `.ssh/` directory | `700` |
| Private key | `600` |
| Public key | `644` |

| Command | Purpose |
|---|---|
| `ssh-keygen -t rsa -b 2048` | Generate a new RSA key pair |
| `ssh-copy-id user@host` | Automatically deploy the public key to a remote user |
