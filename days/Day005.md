# Day 005: Install and Configure SELinux

## 🎯 What I Did Today

Today's task was about SELinux — installing it andthen disabling it in a way 
that actually persists after a reboot, without rebooting the server myself.

**The scenario**: install the required SELinux packages, then permanently disable SELinux
(it'll get re-enabled later after further config). No manual reboot needed since a
maintenance reboot is already scheduled — but the state has to come back as "disabled"
after that reboot, not just right now on the command line.


## Steps I Followed

1. SSH'd into the server the same way as previous days.

2. Installed the SELinux packages:

    ```sh
    sudo dnf install selinux-policy selinux-policy-targeted policycoreutils policycoreutils-python-utils
    ```

3. Edited the SELinux config file directly, since that's what controls the state *after* a
   reboot (not `setenforce`, which only affects the current session):

    ```sh
    sudo vi /etc/selinux/config
    ```

    Set:

    ```
    SELINUX=disabled
    ```

## What I Took Away From This

- `setenforce` only changes the SELinux mode for the current running session — it doesn't
  survive a reboot. If you actually want a persistent change, it has to go in
  `/etc/selinux/config`
- This is why the task specifically said not to worry about the current command-line
  status — the real requirement was about what happens *after* the reboot, which meant the
  config file was the only correct place to make the change
- SELinux isn't all-or-nothing — there's a middle ground (`permissive`) that logs
  violations without blocking them, useful for testing policies before enforcing them

## Notes to Self

| SELinux Mode | Behavior |
|---|---|
| Enforcing | Policies actively enforced, violations blocked |
| Permissive | Violations logged but not blocked (audit/testing mode) |
| Disabled | SELinux completely off |

| Command | Purpose |
|---|---|
| `getenforce` | Check current SELinux mode (session only) |
| `setenforce 0` / `setenforce 1` | Temporarily switch to permissive / enforcing |
| `sestatus` | Detailed SELinux status |
| `sealert` | Analyze SELinux denials |

| File | Purpose |
|---|---|
| `/etc/selinux/config` | Main config — controls the mode *after reboot* |
| `/var/log/audit/audit.log` | Where SELinux violations get logged |
| `/etc/selinux/targeted/` | Policy files (targeted policy, the default) |
